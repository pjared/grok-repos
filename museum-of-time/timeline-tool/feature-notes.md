# Timeline tool / video editor: feature requests (2026-10-25)

Goal (the director): software to edit Museum of Time videos in depth, built with Coding Manager.

Scope update (2026-10-25, the director): the app is the Museum of Time admin interface. The video editor is one part of it.

1. **Shot nodes (Grok Bot):** each timeline node is one shot holding its storyboard frame, its image/video prompt, its voiceover line and its finished clip. Edit one node, regenerate only that clip, and the cut rebuilds around it.
2. **Truth tags (Science Checkpoint):** every exhibit and node gets a tag (documented, legend or invented), so nothing invented reaches a plaque as real.
3. **House standard export (Museum Curator):** a 3–4 minute widescreen episode that cuts into 45–60 second vertical shorts, each stamped "Museum of Time · [Wing] · [Exhibit] · Short N of M".
4. **Text track (Writing Bot):** narration and plaque lines sit under each shot and move with it when shots are cut or reordered.
5. **Character reference slot (Scene Checkpoint):** a locked reference per character (for example Tung's approved panel 6) that every shot pulls from, to stop the look drifting between shots.

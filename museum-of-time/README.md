# Museum of Time

Written archive for the Museum of Time: halls, exhibit scripts, stills, wireframes, and the decisions behind them. Rendered video and audio stay outside git.

## Layout

| Path | What it holds |
| --- | --- |
| `INDEX.md` | Map of the archive and the current exhibits |
| `layout.md` | Master hall layout |
| `decisions.md` | Locked story and site decisions |
| `site/` | Site rules, voices, and era notes |
| `templates/` | Starters for a new exhibit and a Flux cut sheet |
| `exhibits/` | One folder per exhibit: scripts, prompts, voice lines, and stills |
| `timeline-tool/` | Timeline and workshop wireframes, plus feature notes |
| `previews/` | Still previews |
| `assets/stills/` | Face locks, props, and frames |
| `assets/diagrams/` | Floor plan and wall diagrams |
| `assets/badges/` | Curator badge |
| `assets/audio/` | Place for voice exports. The files themselves are not in git. |
| `assets/video/` | Place for rendered packs. The files themselves are not in git. |

`INDEX.md` is the guide to what is current. `layout.md` is the hall order.

## Rendered media

Finished picture and sound live outside this repository. Git ignores `mp4` files under `museum-of-time/` and ignores `mp3` and `mov` files anywhere in the repo. Voice tracks and video packs stay with the person who renders them.
